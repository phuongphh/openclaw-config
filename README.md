# OpenClaw Config

Cấu hình và scripts cho hệ thống OpenClaw AI agent.

## Structure
- `openclaw.json` - Config chính
- `agents/` - Agent configurations  
- `workspace/scripts/` - Automation scripts
- `cron/` - Scheduled jobs

## Setup
1. Copy files vào `~/.openclaw/`
2. Tạo `.env` từ `.env.example`
3. Chạy `openclaw gateway install && openclaw gateway`
